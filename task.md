# Реализация изолированного запуска через пространства имён
- Создайте процесс в изолированных пространствах имён: PID, mount, user, UTS, IPC и network.
- Организуйте синхронизацию между родительским и дочерним процессом через pipe: дочерний процесс ожидает сигнала, пока родитель настраивает отображение UID и GID.
- После получения сигнала дочерний процесс выполняет смену корневого каталога (chroot или pivot_root), монтирует служебные файловые системы (/proc, /dev) и заменяет себя целевой командой через exec.


Полностью rootless, без дополнительной настройки окружения.
